## 做了什么
- **像素办公室** `packages/pixel-office`：房间绘制移植自 v0.1 演示（窗、书架、绿植、桌子、显示器），按部门分区，主管坐在区前地毯上；人物换成原创 8×8 像素机器人（屏幕脸 + 天线），机身颜色按员工区分，眼睛暖黄 = Claude、青色 = Codex；名牌写名字和模型。输入只是一份快照，渲染与数据无关。
- **状态映射**（`apps/console/server/office.mjs`，按 7.1 优先级）：失败（红 !）> 等你（举牌）> 工作中（屏幕滚代码、打字）> 交付待验收 > 暂停（灰色）> 空闲；子任务刚 `done` 时一次性走向主管再走回。点人物弹小卡：在做什么、待处理卡片快捷按钮、看项目、档案。
- **员工抽屉**：档案、模型、技能、本月花费 / 预算、记忆文件（可在网页里编辑，保存即 git 提交）、暂停 / 恢复。
- **皮肤** `packages/skins`：主题 token + 术语表 + 布局（侧栏左右、卡片排列）。界面文案全部走 `t()`；内置"办公室"（默认）和"朝堂"（尚书 / 奏折 / 御书房 / 侧栏在右 / 衬线字体）。
- **用量面板**：按部门 → 员工显示本月 API 折算花费与预算进度；订阅额度显示官方窗口（若在 Paperclip 绑定了订阅账号）或按 5h / 24h / 7d 窗口的 token 估算。
- **新建部门向导**：基本信息 → 人员（模板、适配器、"全部用同一个"）→ 技能 / 例行任务 → 预算 → 预览（像素头像）并创建；内置科研部、公司部、生活部三个部门包。
