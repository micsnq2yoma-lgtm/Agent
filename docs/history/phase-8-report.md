# Phase 8 报告 · 合并外壳（一个端口、一条侧栏）

日期：2026-11-14　计划：`docs/phase-8-plan.md`　方案：`docs/PLAN.md` v0.5（已用用户导出的 v0.5 覆盖）

## 做了什么
- **视图迁移**：`apps/console/src` 整体移到 `vendor/paperclip/ui/src/agentself/`（git 历史保留）。
  - 原来靠组件状态切页，现在改成 Paperclip 路由，挂在公司前缀下：

    | 页面 | 路由 |
    | --- | --- |
    | 工作台 / 像素团队 | `/:prefix/agentself` |
    | 部门 | `/agentself/departments/:key` |
    | 新建部门 | `/agentself/departments/new` |
    | 项目、例行任务、能力与工具、用量与预算、设置、已归档 | `/agentself/projects` 等 |

  - `AgentselfRoot` 包在公司布局外层，统一加载上下文和消息流，供侧栏和各页共用；项目抽屉、员工抽屉和提示条在任何页面都能弹出。
  - 样式全部收在 `.agentself` 类下面，不影响 Paperclip 页面。
- **默认首页**：打开 `http://127.0.0.1:3100` 会跳到 `/AGE/agentself`，即工作台。
- **一条侧栏**：`Layout.tsx` 的主侧栏换成 `AgentselfSidebar`，Paperclip 的上下文二级侧栏、底部账号 / 公司菜单不再渲染。侧栏结构按 7.0：
  - 工作台、项目
  - 部门（各部门 + 新建部门）
  - 管理（默认折叠，展开状态会记住）：组织图、全部员工、能力与工具、例行任务、用量与预算、记录
  - 设置
  - 我 · 通知
- **隐藏入口**：收件箱、仪表盘、新建任务、智能体聊天、Cases、Goals、多公司切换都不在新侧栏里。代码和路由一行没删。
- **应用内跳转**：
  - 项目抽屉加了"完整页"（任务详情），子任务标题也能点进去。
  - 员工抽屉加了"完整页"（员工详情）。
  - 设置页"高级"区原来是一个开新标签页的后台链接，现在改成 7 个应用内入口：公司设置、密钥、适配器、插件、实验功能、实例访问、连接器。
- **接口统一**：
  - 本地服务（`apps/console/server`）只响应 `/agentself/api/*`，不再托管页面，也不再代理 `/api`；它只监听 127.0.0.1。
  - Paperclip 服务新增 `server/src/agentself/proxy.ts`，在 JSON 解析之前把 `/agentself/api/*` 转给它，不转发 cookie 和 authorization。
  - `scripts/start.mjs` 的健康检查改用新路径，服务名改为 `agentself-local`。
- **清理**：
  - `apps/console` 删掉了前端构建（`dist`、`index.html`、vite 配置，以及之前误提交的 `dist`）。
  - `spikes/shots` 截图不再入库，因为里面可能出现本机路径。
- **验收脚本**：
  - P2、P3、P6 皮肤三个脚本改为只访问 3100，侧栏按钮改成链接。
  - P3 里皮肤行的选择器原来会同时命中"使用"和"导出"两个按钮，改成精确指向"使用"。
  - P2 的探针任务跑完后直接删除，不留测试数据。
  - 新增 `scripts/acceptance/p8-shell.mjs`。

## 与方案的偏差
1. **:3200 没有完全消失**：本地服务仍监听 `127.0.0.1:3200`，但只作为 3100 背后的接口，只听本机，不托管页面。浏览器和所有验收脚本只访问 3100。PLAN 第 2 节说"之后可逐步迁入 Paperclip 服务端"，这一步留到以后。
2. **从任务完整页到运行记录要多点一下**：Paperclip 新版任务页的聊天视图里，员工回复上没有运行记录链接（它的数据模型不带 run id）。要加链接就得改 task-chat 的模型和多个组件，超出"只改挂载点"的范围，所以没改。现在的路径是：点任务页右侧属性栏的"负责人"，进员工详情，再点进这次运行，全程在同一个应用里。P10 做员工完整页和项目抽屉时，可以在抽屉或任务页直接列出运行记录。
3. **Cases 打不开不是我们隐藏的**：本实例的实验功能 `enableCases` 是关的，所以 `/AGE/cases` 被上游跳到仪表盘。这是上游的原有行为，和隐藏入口无关；打开实验开关后就能访问。
4. **组织图和全部员工目前是同一页**：上游新版界面把 `/org` 直接跳到 `/agents/all`，所以"管理"区这两项打开的是同一个页面。P10 会处理。
5. **还没处理的界面细节**：
   - Paperclip 的顶部面包屑栏还在，Agentself 页面上方会多出一条空白栏。
   - 朝堂皮肤"侧栏放右边"的布局，在 Paperclip 外壳里不再生效。
   - 皮肤配色还没映射到 Paperclip 的样式变量。
   
   这三项分别属于 P9 / P10，本期不做。
6. **其他布局没改**：手机端不在范围内。旧版布局（`Layout.production`，只在实例显式关掉"精简界面"时才会用）没有改。
