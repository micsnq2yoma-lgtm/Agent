# Phase 2 报告 · 消息流（工作台）

日期：2026-11-14

> 计划说明：P2 起连续推进，没有单独写 `phase-2-plan.md`；计划要点即下文"做了什么"的前三条。

## 做了什么
- **独立工作台** `apps/console`（Vite + React 19），按用户决定做成独立网页：本地服务 `server/server.mjs`（:3200）托管页面、把 `/api` 代理到 Paperclip、提供 `/agentself/*`（前台、设置、记忆、部门、办公室快照、皮肤、IM 状态）。设置页"高级设置"跳 Paperclip 后台。
- **卡片**：`src/lib/cards.ts`（纯函数 + 单测）从 Attention、顶层 `in_review` issue、前台回答组装三类卡片：要你拍板（互动提问 / 审批 / Decision / 预算）、交付结果（主管汇报确认，含 report 预览、验收通过 / 返工）、前台即答；运行失败归中档。排序：拍板在前，其余按时间倒序；处理完收进"已处理"。
- **就地处理**：选项、批准、确认汇报、返工（带意见）、稍后（Paperclip inbox snooze 3 小时）、已读。
- **前台**（`server/frontdesk.mjs`）：用本机 Claude Code（`claude -p --model haiku`，可联网搜索）一次完成分类 + 回答：即答（不建任务）/ 任务（建在部门 project 下指派主管）/ 补充（评论到已有任务，唤醒负责人）/ 判断不出（让用户点选部门）。输入框支持"交给：自动 / 指定部门 / 指定员工"和"对外动作：先问我 / 直接做"。
- **项目抽屉**：子任务树（含返工次数）、report、文件、时间线、插一句话（可发给主管或某个子任务的员工）、暂停 / 取消。
- 浏览器通知：新的高档卡片在页面隐藏时弹系统通知。

## 与方案的偏差
- 主管汇报时 Paperclip 自带技能会额外发一个"请求确认"互动（目标是 report 文档）。工作台把它合并成一张"交付结果"卡片，按钮用它自带的"验收通过 / 需要修改"，不再重复显示。
- 低档"任务进展"不进工作台，只出现在项目抽屉的时间线（与 7.0 一致）。
