# Phase 10 计划 · 页面整合

日期：2026-11-14　依据：`docs/PLAN.md` v0.5 第 7.0 节合并表、第 9 节 P10；设计稿 `docs/handoff/v0.5/design/boards/`（Dept、Employee、Team、Settings）。

> 说明：和 P9 同一天连续执行（用户要求剩下的一次做完）。

## 做法
1. **部门页** `/agentself/departments/:key/:tab`，五个标签：
   - 概览：本部门的像素分区、待拍板事项、进行中的项目
   - 成员：成员列表，可快速查看或进完整页
   - 例行任务：只列本部门
   - 能力：只列本部门成员实际用到的技能
   - 预算：本部门用量 / 预算

   侧栏里点部门名，直接进部门页。
2. **员工完整页**：由 `ui/src/App.tsx` 用 `EmployeeRoute` 包住 Paperclip 的员工详情。
   - 上方是一条标签栏：档案、记忆，以及 Paperclip 原有的概览、指令、技能、运行时（模型）、密钥、工具、权限、运行记录、预算。
   - 档案和记忆两个标签由我们渲染，和员工抽屉复用同一套组件；其余标签仍由 Paperclip 渲染。
   - 员工抽屉里的"完整页"直接打开档案标签。
   - 这也补回了 P8 去掉二级侧栏后，员工详情没有子导航的问题。
3. **合并页**（都在 Agentself 侧栏下，用标签切换，Paperclip 的页面组件直接嵌在标签里）：
   - 能力与工具：技能（Paperclip 技能页）/ 连接器（Paperclip 应用页）/ 权限（对外动作）
   - 用量与预算：用量（我们的面板）/ 预算规则 / 费用明细（Paperclip 审计页）
   - 记录：活动 / 运行审计 / 产物 / 审批历史
   - 组织图：嵌入 Paperclip 组织图。新版界面的 `/org` 会跳到员工列表，所以单独做一页。
   - 例行任务：一个页面按部门分组，点名称进 Paperclip 的例行任务详情。
   - 项目：顶层任务按部门分组。
   - 设置：通用 / 前台 / 飞书 / 预算 / 对外动作 / 皮肤 / 高级，高级里是 Paperclip 的公司和实例设置入口。
4. **工作台**：
   - 像素团队顶部加统计条（运行中、阻塞、等你拍板、本月花费），像素团队视图下也保留输入框。
   - 输入框旁加"高级新建"，打开 Paperclip 原来的新建任务表单，并按"交给"的选择预填负责人和项目。
5. **验收**：新增 `scripts/acceptance/p10-pages.mjs`；P2、P3、P6、P8、P9 验收脚本和 Vitest 全部重跑。
