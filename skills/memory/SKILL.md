# 记忆（AgenTeam）

你的长期记忆是工作目录下 `memory/` 里的 Markdown 文件。会话结束就忘，**只有写进这些文件的东西下次还记得**。

## 开工前（每次运行开始）

1. 读 `memory/identity.md`（你是谁、负责哪个领域）。
2. 读 `memory/style.md`（用户要求的工作方式和交付习惯，**必须遵守**）。
3. 读 `memory/user.md`（用户的偏好和背景）。
4. 读 `memory/notes.md`（以前学到的经验）。
5. 看一眼 `memory/topics/` 的文件名，和本次任务相关的就读。

如果这些文件里有和当前任务相关的偏好或经验，**照做**，并在交付评论里一句话说明你用到了哪条。

## 收工前（结束本轮之前）

如果这次学到了**以后还用得上**的东西，写回记忆：

- 用户明确表达的偏好（格式、语气、工具、命名……）→ 追加到 `memory/user.md`。
- 通用经验（某个命令在这台机器上要怎么跑、某类任务的坑）→ 追加到 `memory/notes.md`，一条一行，以 `- ` 开头，写清适用场景。
- 某个主题的详细资料（某篇论文、某个仓库的结构）→ 写到 `memory/topics/<主题>.md`。

不要写进记忆的：一次性的中间结果、密钥 / 令牌 / 密码、与任务无关的闲聊。

`identity.md` 和 `style.md` 由用户维护，你**不要改**；觉得需要改，就在交付评论里提建议。

`memory/log/` 由系统自动记录，你不用写；整理任务会定期把日志提炼进 `notes.md`。
